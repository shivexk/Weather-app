🌦️ Weather App

A simple weather application built during an AI/ML workshop at Thapar Institute.

The app fetches real-time weather data using a weather API and displays it through a simple, user-friendly interface.

🚀 Features

* 🌡️ Real-time weather information
* 📍 Search weather by location
* 💨 Displays weather details such as temperature and conditions
* 🔄 Fetches data through an external weather API
* 💻 Simple and responsive interface

🛠️ Tech Used

* HTML
* CSS
* JavaScript
* Weather API
* AI-assisted development

⚙️ How It Works

1. The user enters a location.
2. The application sends a request to the weather API.
3. The API returns the current weather data.
4. The application processes the response and displays the information.
